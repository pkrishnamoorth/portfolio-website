# KRISHNAMOORTHI Portfolio Website

A personal portfolio website built with HTML, CSS, and JavaScript.

## Project Overview

This repository contains a responsive portfolio landing page for `KRISHNAMOORTHI.P`. It includes:

- `index.html` — page structure and section layout
- `styles.css` — custom styling and responsive design
- `main.js` — menu toggling and active navigation behavior
- `km.jpg` — favicon image used in the page

## Features

- Fixed header navigation with active link styling
- Responsive mobile menu
- Animated page sections using AOS (via CDN)
- Dark theme with modern gradient accents
- Social media icon placeholders

## Usage

1. Open `index.html` in a browser.
2. Use the navigation menu to jump between homepage sections.
3. On mobile, tap the menu icon to open and close the navigation.

## Development

No build tools are required. The project is static and runs in any modern browser.

If you want to customize it:

- Edit `index.html` for content and section structure
- Edit `styles.css` for layout, colors, and responsive behavior
- Edit `main.js` for menu and navigation interactions

## Notes

- The page uses external CSS from Boxicons and AOS.
- The current homepage profile and contact content are contained in `index.html`.
